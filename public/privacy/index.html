Privacy Policy

Last updated: 31 October 2026

This policy covers the personal tools Zaky Ashari ("I") runs with Google sign-in, currently the Google OAuth client named rclone, which backs up my own laptop to my own Google Drive. These tools are for my personal use only and are not offered to anyone else.

What data the app accesses

With your consent on Google's sign-in screen, the app can read, create, update and delete files in the Google Drive account that signs in. It uses this access only to upload backup copies of files from my computer and, when I need them, to download those copies again.

Where data is stored

  • The sign-in token Google issues is stored only on the computer that runs the backup, in the local rclone configuration file.
  • Backed-up files are stored only in the signed-in user's own Google Drive. Sensitive files are encrypted on the computer before upload.
  • No data is sent to, or stored on, any server I operate. There is no analytics or tracking.

Sharing

Google user data is not sold, shared with third parties, used for advertising, or used to train AI models.

Google API Services User Data Policy

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

You can revoke the app's access at any time at myaccount.google.com/permissions. Revoking access stops all further use. Backup files stay in your Google Drive until you delete them there.
